What do the classifications mean?
Needs review
A concern reached the review threshold. Inspect its evidence.
Consider
A milder concern reached the threshold, such as a function that likely mixes separate jobs or tests that could share one parameterized case.
Note
An optional improvement to code that reads well as it is. Notes never fail the gate.
Clear
The selected checks support acceptable behavior. This is not proof of safety.
Uncertain
The evidence did not support a confident decision.
Needs context
A material contract, caller or other fact is missing.
Not applicable
The rule is outside this scope or no applicable candidate was selected. This does not mean the file is safe.
Error / pending / skipped
These are execution or scope states, not code-quality judgments.
